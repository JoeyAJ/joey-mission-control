## Purpose / blueprint / progress

Durable owner records preserve purpose fields, created record time and approved revision.
Edits are proposals; only explicit Joey approval applies them. Purpose.createdAt is the
record's creation time, not an invented original project creation date.
Blueprint supports weighted milestones and features with all six statuses. Human forms
create/edit blueprint drafts; accepted features expose matching Evidence references.
Marking a feature complete needs verified reference/time evidence and Joey approval.
UI disables completion where no matching verified evidence exists.

Progress is milestone-weighted completion of eligible feature weights; optional/deferred
work is excluded. No guessed in-progress credit. No denominator returns unknown progress,
not 0%. Whole-project COMPLETED may coexist with 70% or any other blueprint progress.

revision-checked and recorded. Agents may propose purpose/blueprint changes but direct
