## Joey 的修訂權與狀態語意

初心／成果／成功定義、下一功能、藍圖增刪／排序／權重，都可以提出修改。Joey 明確批准後才更新本機 canonical human/product owner state；歷史來源基準仍保留。批准提案及決策留在 revision ledger，介面可展開已批准的修改。它没有自動寫回受管產品倉庫或外部 Canonical Memory。

本機 token＋Joey 明確確認仍沿用 V0.3 的 local attestation 邊界，没有新建遠端身分驗證；Agent 不得冒充 Joey 批准。Public snapshot 不提供持有者寫入。

未確認範圍／權重／項目時，進度為 null 並顯示「藍圖整理中」。Joey 批准範圍及權重、且没有待確認項目後，才計算加權完成比例；OPTIONAL／DEFERRED 不納入分母。COMPLETED 功能必須具備對應的批准驗收證據或已記錄的批准階段發布鏈，單純已核對的程式／文件不能充當產品驗收。

工作狀態分開處理技術阻塞、歷史不足、等待同步、Joey 選擇、待驗收及沒有進行中任務。未啟動的下一產品能力顯示等待 Joey 決定，不把工程前置限制說成整個產品被阻塞。實際工作樹衝突或進行中任務的技術阻塞保留優先權；缺 Git 觀察／Handoff 欄位顯示 Awaiting sync，原本 Continue 的安全檢查仍保留。
