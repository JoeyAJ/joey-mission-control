## Changes
- A single verifiedDecisionItems classification supplies Dashboard cards/table, Project Detail, Attention categories/counts and backend attention. Generic approval phrases do not qualify.
- A decision requires explicit WHAT (a request or choice), WHY, pending/unresolved STATUS and canonical source with documented/verified provenance and SHA-256 fingerprint. Missing/unverified, deferred/resolved, factual descriptions and duplicate/empty duplicate fields are rejected.
- Each legitimate waiting indicator is a button. It navigates to Project Detail and focuses its stable decision section. That section shows project, WHAT, WHY, status, source, optional verified Agent/model, and expandable original evidence. Its status button focuses the same section.
- Incomplete decision candidates show 資料待整理; raw canonical evidence is retained. The empty category is labeled Joey 決策項目 · 0 rather than a passive waiting badge.
- Added consistent Traditional Chinese, Korean and English labels. Existing styling, responsive rules and accepted external links are preserved.
