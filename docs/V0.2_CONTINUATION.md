- Needs review -> Resolved; interpretation -> Ready to confirm.
- Ready to confirm -> In progress (requires confirmation) or Resolved.
- In progress -> Resolved.
- Resolved -> Needs review (clears prior interpretation, confirmation and promotion markers).

API and store schema validation remain active. Inbox filtering is client-only. Initial load, entering Inbox, explicit reload, and successful mutations reread the local list.
