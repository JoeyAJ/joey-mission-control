Callback commits also advance that generation.

Callback snapshot and commit use that same lock. A commit requires unchanged session bytes **and generation**, plus current callback and expiry checks. Logout therefore leaves a tombstone even when custody returns to identical empty bytes. No framework, Auth/SMTP/MFA/RLS/settings, source grants or credentials were introduced.
