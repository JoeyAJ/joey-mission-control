## Architecture and authority

`src/project-state/` validates and migrates canonical Project State and applies
explicit owner commands through durable atomic JSON storage and revision checks.
`public/project-state.js` is the shared pure derivation engine for Current Phase,
Blueprint, Next Waypoint, Mission Path and Project Status. Derived views are not
stored as independent facts. Confirmation queues and future decisions remain separate.
Joey mutation uses local token and explicit local attestation, not remote identity.
