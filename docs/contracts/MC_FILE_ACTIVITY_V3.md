# Explicit opt-in repository file metadata

First slice: `mc.repository-run.v3`, model-neutral explicit per-task metadata, under existing checkout/report permissions. v1 remains default and strict; v2 remains strict. No old header/events are upgraded. v3 inherits taskKind/delivery/result/lifecycle and requires immutable `activityMode=EXPLICIT_FILE_METADATA`, `activityPaths` (1–8 exact task-authorized safe tracked relative paths) and each event `activity:null` or one bounded `mc.file-activity.v1` object. Existing 16 KiB report / 64 events / 20 runs and 128 KiB private continuation caps are unchanged. Each run allows at most eight file actions; exhausted budgets need a new authorized same-scope predecessor run, never history deletion.

Exact activity keys: schemaVersion, qualification=AGENT_REPORTED_METADATA, scope, actor, action, path, contentSha256, previousContentSha256, byteLength, workHeadSha, observedAt, precision. Scope exactly repeats projectId/track/repositoryId/runId/taskId/workRef; actor equals registered Agent name. Only progress may carry activity. All other events explicitly use null. No source, diff, command, transcript, hidden reasoning, attestation or arbitrary additional field is permitted.

FILE_READ means `REPORTER_BOUNDED_READ`: an explicitly invoked reporter reads authorized bytes to compute SHA256. It does not prove the Agent cognitively inspected them or that an editor/tool transcript exists. Previous digest is null. FILE_CHANGED means `OBSERVED_DIGEST_CHANGE`: current bytes differ from the last published same-run/same-path observation, whose digest must match previousContentSha256. It is an Agent-attributed change declaration plus before/after observation, not independent proof of who edited a file. Times/sequence and observed-at order must agree; observation cannot predate this run or follow its event. workHeadSha records checkout HEAD at observation; dirty worktree bytes are bound by contentSha256, not falsely claimed to be committed at that HEAD.

All metadata remains Agent reported. Git Contents read/hash verifies report bytes/scope, not execution or current file content. Unknown/cross-scope/actor/path/time/lineage/precision fields fail closed. A read refresh does not renew original observation time. Schema provides strict shape/static constraints; code additionally enforces equality, manifest membership, lifecycle/source/lineage/time/CAS and byte bounds. Prototype-named own JSON keys are rejected at header and nested levels.

## Explicit receiving-Agent commands

Choose v3 only when actual file metadata is desired and already authorized. Use the normal fresh source/profile packet and started/append commands; started contains delivery:null and activity:null. The manifest grants no extra filesystem/content-sharing access.

```
node mc-reporter.mjs file-event --packet source-packet.json --meta registration.json --run RUN_ID --expected-file-sha PREVIOUS_BLOB --expected-sequence PREVIOUS_SEQUENCE --file-path EXACT_MANIFEST_PATH --file-action read --event-id UNIQUE_ID --output file-event.json
```

Preparation is mode 600 / create-only, performs no report write/upload, and returns FILE_METADATA_EVENT_PREPARED_NOT_PUBLISHED. Verify the prepared metadata, then invoke the existing append/CAS command with that event. `changed` uses the same command after a real authorized edit and requires its prior published observation. No implicit publishing, glob, hook, watcher, daemon, timer heartbeat or arbitrary repository read exists. Copied generic helper uses receiving Agent's existing runtime Git authorization; no credentials are provisioned by MC.

Filesystem boundaries: checkout root and work ref must match; paths must be exact declared Git-tracked safe text paths, at most 160 characters and 65,536 bytes. Hidden/sensitive/inventory/ledger/transcript/reasoning/generated/data/vendor paths, traversal, symlinks, hardlinks, non-files, binary/invalid UTF8, credential-shaped content and changing-read bounds are refused before metadata output. Only bounded bytes/digests are held transiently, never uploaded. `.git`, `.aws`, `.codex`, `.agents`, `.env` and private collections cannot be selected. No source/diff sharing scope is inferred from this mode.
