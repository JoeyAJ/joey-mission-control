Hash contract: all package files use SHA256 of exact UTF-8 bytes, with byte count in manifest. `manifest.files` contains exactly the three payload filenames with `{sha256, bytes}`; exportId/dataClass match context. `filteredSha256` hashes canonical JSON of `{projectId, documentKind, fields}`. fields consists of only claims with that sourceId, entries `{field,value,missingReason}`, sorted by ASCII field name. Canonical JSON recursively sorts object keys, preserves array order, UTF-8, no ASCII escaping and no extra whitespace/newline. Python: `json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(',', ':')).encode('utf-8')`. Hash claims including nulls. The consumer verifies this filtered hash and references; it cannot claim it re-read/hash-verified the whole original Memory based solely on originalSha256.
