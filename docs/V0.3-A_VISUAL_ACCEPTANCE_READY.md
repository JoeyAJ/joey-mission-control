## 互動、可讀性與效能

Liquid hover 使用單一 delegated pointer listener、DOM CSS variables、最多一個待執行 requestAnimationFrame。滑鼠移動不重新 render，沒有 per-card animation loop、canvas 或 particle engine。離開玻璃區域清除局部光感。

選定 tab 使用 10 秒緩慢玻璃光感；僅真實 working 狀態才允許輕微狀態燈 pulse。prefers-reduced-motion 會關閉 ambient animation、cursor movement 與過渡，保留靜態 hover 與可見 focus。

狀態同時以文字、符號／形狀與 semantic color 表達；blocked／error、paused、waiting、completed、progress、planned、ready、working、unknown 使用共用 tokens。鍵盤任務切換仍支援方向鍵、Home、End。已驗證實際 focus outline 為 2px cyan。繁體中文正文使用一般 system 字體，mono 僅用於編號與讀值。

桌面為 Hero → 三儀表 → 航線，右側狀態與決策。較窄筆電／平板將右側區移到下方；手機為單欄、橫向專案切換列與底部導航，側欄輔助資訊收起。已在 Joey View 實測 1440、1280、1100、1024、850、768、390、320px，頁面寬度均等於視窗寬度，無頁面橫向溢出。看板只在自己的區域內捲動。
