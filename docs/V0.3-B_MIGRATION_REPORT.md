## Mapping

- 舊 lifecycle IN_PROGRESS → DEVELOPING；未記錄 → UNKNOWN。
- 舊 AWAITING_ACCEPTANCE → WAITING，代表仍待驗收，沒有改成完成。

- OPTIONAL / DEFERRED → PAUSED；legacyStatus 保留原值。
