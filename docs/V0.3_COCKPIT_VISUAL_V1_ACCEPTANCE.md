## 主要視覺變更

- 指令列整合 Mission Control、語言、重新讀取、本機設定及小型系統讀值；來源校對與本機狀態取自現有資料，未增加虛構健康指標。
- 深海軍藍背景、儀表面板、啟用控制形成三層深度，使用細邊線、內側亮邊、克制的漸層與陰影。
- 選定任務以大型 Mission Header 顯示名稱、既有狀態與待確認數量。初心保持繁體中文可讀性。
- Current Phase、Blueprint、Next Capability 成為主要儀表組。Blueprint 使用分段儀表；尚未確認時顯示 CALIBRATING／藍圖整理中，沒有百分比。
- 既有里程碑轉為連接節點的 Blueprint Flight Path；順序、狀態、描述與依據保留原值。
- 狀態讀值、Joey 決策中心、生命週期控制與折疊 Flight Recorder 分區。決策中心使用既有待確認問題與提案，不混入工程警告。
- 生命週期改為六個狀態按鈕。選擇只是草稿，仍須明確套用；完成／封存確認與既有權限規則保留。
- Agent 控制台維持原有技術密度與操作介面；座艙風格限定 Joey View。

## 響應式與無障礙

桌面：任務識別與初心 → 三個主儀表並列 → 橫向／混合航線 → 決策與生命週期區。平板適當使用兩欄，Blueprint 獨立一列。手機使用單欄，依序為 Current Phase、Next Capability、Blueprint、Mission、Flight Path、Decision、Lifecycle；任務切換列可水平捲動。

已實際檢查 1440、1280、1024、768、390、320px：頁面寬度均等於視窗寬度，無頁面橫向溢出，始終只有一個選定任務面板。生命週期看板在自己的區域內捲動。

狀態同時有文字、符號與顏色；互動控制有可見焦點。任務切換支援方向鍵、Home、End，以及正確的 tab／tabpanel 關聯。狀態按鈕使用 aria-pressed；僅選擇不會寫入資料。表單保留標籤。已驗證 prefers-reduced-motion 關閉過渡效果並避免平滑捲動；沒有持續裝飾動畫。本次不是完整 WCAG 認證稽核。
