# Joey Mission Control

Joey's project control tower: one overview of every project, the Agent working on it, reviews and handoffs.

- Overview (Owner sign-in): https://joey-mission-control-one.vercel.app/#joey
- Agents: start at [AGENT_CONTROL.md](AGENT_CONTROL.md). To register a new project ("登記到 MC"), follow section A there.
- MC development state: [HANDOFF.md](HANDOFF.md) and [PRODUCT_CHARTER](docs/PRODUCT_CHARTER.md).
